# 🗾 Omotenashi Concierge (おもてなし案内所)

> **Authentic 47-Prefecture Japan Travel Companion & Seasonal Itinerary Planner**
> Crafted with true *Omotenashi* (Japanese hospitality) spirit.

---

## ✨ Features & Capabilities

### 1. 🗾 Interactive Dual Map of Japan (47 Prefectures)
- **Geographical Vector Map**: Accurate vector map of all Japanese regions and archipelagos (Hokkaido, Tohoku, Kanto, Chubu, Kansai, Chugoku, Shikoku, Kyushu, Okinawa) with zoom/pan navigation, region focus filters, and hover previews.
- **Regional Matrix Grid**: Modular view for instant scanning and filtering by region.

### 2. 🌸 Authentic 4-Season Cultural Dataset
- Comprehensive cultural data covering **all 47 prefectures**:
  - Japanese Kanji & Romaji names
  - Capital cities & regional geography
  - Signature culinary specialties (e.g., Sapporo Soup Curry, Hakata Tonkotsu Ramen, Kagawa Sanuki Udon, Hiroshima Okonomiyaki, Kyoto Kaiseki & Uji Matcha)
  - Sacred Shinto shrines, historic castles, UNESCO heritage sites, and hidden nature gems
  - Traditional Matsuri festivals with real dates
  - Signature *Omiyage* (regional souvenir gifts) & local insider secrets

### 3. 🔊 Native Audio Pronunciation & Zen Soundscapes
- **Web Speech API**: 1-click authentic Japanese voice pronunciation for prefecture names, attractions, dishes, and essential travel phrases.
- **Web Audio API Ambient Synthesizer**: Soothing synthesized Japanese soundscapes (Kyoto Zen Rain, Bamboo Shishi-odoshi Water Drop, Summer Furin Windchime, and Bronze Temple Bell).

### 4. 📅 3-Day & 5-Day Interactive Itinerary Builder
- Morning (朝), Afternoon (昼), and Evening (夜) time-slotted activity pacing.
- Interactive completion checkboxes with confetti celebration.
- Direct 1-click Google Maps lookup links for every attraction.
- Personal custom notes and activity adder.

### 5. 🧳 Pocket Travel Concierge Toolkit
- **Audio Phrasebook**: Essential Japanese phrases with Kanji, Romaji, English, and instant audio pronunciation.
- **Etiquette Guides**: Visual etiquette rules for Onsen hot springs (tattoo policies, washing rituals) and Shinto Shrines vs. Buddhist Temples.
- **Transit & IC Card Guide**: Suica/Pasmo/ICOCA setup, Shinkansen bullet train reservations, and oversized luggage rules.
- **Trip Budget Estimator**: Live currency conversions (JPY to USD, EUR, GBP, AUD, CAD) with budget breakdowns for Backpacker, Explorer, and Luxury Ryokan travel styles.
- **Travel Essentials Packing List**: Seasonal packing checklist with localStorage persistence.

### 6. ⛩️ Goshuincho Stamp Rally (Gamification)
- Collect traditional red seal (*Hanko*) stamps for every prefecture you explore or plan.
- Unlock explorer ranks from *Travel Initiate* to *Imperial Legend (天下統一 47/47)*!

### 7. 📤 Export & Sharing Suite
- **Apple / Google Calendar (`.ics`)**: Download scheduled events directly into your calendar.
- **Markdown / Notion Checklist**: Copy formatted itinerary for Notion, Obsidian, or Apple Notes.
- **Print / PDF**: Clean printer-formatted travel guide.
- **URL Sharing**: Direct hashtag state URLs (e.g. `/#kyoto`, `/#hokkaido`).

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS + Sumi-e Japanese Glassmorphism Design System
- **Icons**: Lucide React
- **Audio & Animations**: Web Speech API, Web Audio API, Canvas Confetti

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Code linting
npm run lint

# Build production bundle
npm run build

# Deploy to GitHub Pages
npm run deploy
```
