# Omotenashi Concierge

A React + Tailwind web app for GitHub Pages that provides an interactive SVG map of all 47 Japanese prefectures.

## Features

- Interactive, responsive SVG prefecture map (all 47 prefectures)
- Deep in-app seasonal data (Spring, Summer, Autumn, Winter) per prefecture and region
- Auto-generated 3-day timeline itinerary (food, historical sites, festivals)
- Local bookmark storage with `localStorage`
- Mobile-friendly layout optimized for small screens

## Development

```bash
npm install
npm run dev
```

## Build & Deploy (GitHub Pages)

```bash
npm run build
npm run deploy
```
